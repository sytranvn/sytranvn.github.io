Note on Fine tuning Yolo Models

February 1, 2026 2-minute read
As Yolo26 is optimizing more for edge devices. I want to try fine tuning it for chess pieces detetion and regconition task with mobile devices. This note is by product of it.

Ultralytics provides method to fine tuning YOLO model out of the box. Just 3 lines of code and you can create your own custom model.

from ultralytics import YOLO

# Load a model, pick one of them
model = YOLO("yolo26n.yaml")  # build a new model from YAML
model = YOLO("yolo26n.pt")  # load a pretrained model (recommended for training)
model = YOLO("yolo26n.yaml").load("yolo26n.pt")  # build from YAML and transfer weights

# Train the model
results = model.train(data="coco8.yaml", epochs=100, imgsz=640)

If you want to feed custom dataset, Roboflow Universe likely has what you need. Just look it up and download the dataset in Yolo26 format. Unzip downloaded file in your project and you are ready to train.

The model.train method is simple, but you can add extra parameters to it. Full list of settings is well documented.

The batch setting is what you might want to change. It is 16 by default, if you still have abundant resources, you can increase it, or set the value to batch=-1 to auto use 60% GPU memory. Or batch=0.90 for 90% GPU memory.

The imgsz is 640 by default. This affects model accuracy and computational complexity. So you might want to play with it.

The cache option allow dataset to be cached in RAM. And improve training speed.

Ultralytics supports logging to many tools for experiment tracking and visualization. I use Weights and Biases.

# Install the required packages for Ultralytics YOLO and Weights & Biases
pip install -U ultralytics wandb
# Enable W&B logging for Ultralytics
yolo settings wandb=True

Pay attention to GPU temperature if you are training on your hardware. Set alert for gpu.{gpu_index}.temp if its too hot. You can stop training from W&B web interface without touching your computer.

def alert_on_hot_gpu(trainer):
    # Specify the metric and threshold
    # Note: YOLO stores metrics in trainer.metrics (e.g., 'metrics/*')
    threshold = 85
    current_map = trainer.metrics.get('metrics/gpu.0.temp', 0)
    
    if current_map > threshold:
        print(f"\n[Alert] GPU Temperature {current_map:.4f} exceeded {threshold}")
        # Raising SystemExit stops the process cleanly
        if wandb.run:
            wandb.run.alert("Hot potato", f"\n[Alert] GPU Temperature {current_map:.4f} exceeded {threshold}")
        # or you can raise Exception to stop immediately

model.add_callback("on_train_epoch_end", alert_on_hot_gpu)
